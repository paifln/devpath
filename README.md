# Мой путь в разработку

Личный трекер из 208 тем: Python-backend + AI Engineer. Весь интерфейс, стили, данные и логика находятся в `index.html`. Сборка, npm и сервер не нужны.

## Запуск

Откройте `index.html` двойным щелчком в современном браузере. Единственный внешний ресурс — Google Fonts; без интернета используется системный моноширинный шрифт.

## GitHub Pages

Добавьте `index.html` и `README.md` в репозиторий, отправьте изменения в GitHub. В Settings → Pages выберите Deploy from a branch, вашу ветку и папку `/ (root)`, затем Save. После публикации откройте адрес, показанный GitHub.

## Использование

- Отмечайте освоенные темы. Дата завершения видна при наведении.
- Кнопка заметки открывает поле под темой; изменения сохраняются с задержкой 300 мс. Фиолетовая точка обозначает заметку.
- Ctrl/Cmd+K открывает поиск по темам и разделам; стрелки выбирают результат, Enter открывает его, Esc закрывает окно. Поддерживаются запросы `join`, `джойн`, `docker` и `докер`.
- `/` переводит фокус в фильтр поиска, J/K перемещают фокус по видимым флажкам, пробел переключает флажок. Tab проходит по элементам управления.
- Разделы и группы боковой панели запоминают свёрнутое состояние.

## Хранение и резервные копии

Состояние хранится в localStorage под ключом `roadmap.v1`: `done`, `notes`, `collapsed`, `pinned`. Экспорт скачивает `roadmap-progress.json`. Регулярно сохраняйте этот файл отдельно, особенно перед очисткой браузера или сменой устройства. Импорт проверяет структуру, ID и типы данных и спрашивает подтверждение перед заменой. Сброс требует двух подтверждений.

Данные принадлежат конкретному браузеру и адресу: локальный файл и GitHub Pages имеют отдельные хранилища. Переносите прогресс экспортом и импортом. Если браузер блокирует хранилище, приложение продолжает работать в памяти и сообщает об ошибке; перед закрытием сделайте экспорт. Синхронизации с сервером нет.

## Изменение тем

Редактируйте константу `DATA` в секции DATA внутри `index.html`. Структура: части → разделы → темы. Тема содержит постоянный строковый `id` и `title`. Можно переименовывать `title`, сохраняя `id`: отметка и заметка останутся. Обратные кавычки в заголовке превращаются в небольшие блоки кода.

Не перенумеровывайте существующие ID при вставке или перестановке тем. Для новой темы выберите новый, никогда не использовавшийся ID, например `py-37`. Сохраните резервную копию перед изменением структуры. Проверка импорта намеренно отклоняет неизвестные ID: импортировать старую копию следует в версию маршрута с соответствующими темами. При изменении количества тем обновите проверку `console.assert` и статическую подпись в шапке (исходная программа содержит ровно 208 тем).

## Принятые решения

«В процессе» показывает все ещё не освоенные темы. Серия учитывает последовательные календарные дни с завершёнными темами; вчерашняя серия сохраняется до конца текущего дня. Тепловая карта показывает последние 84 дня, включая сегодня, по локальному времени браузера. Снятие отметки удаляет её дату из статистики; повторная отметка записывает новую дату. Заметки вставляются как текст, без выполнения HTML. При переходе из поиска фильтр сбрасывается, чтобы найденная тема была видна. Приложение публикуется пользователем через GitHub Pages; внешнее размещение автоматически не создаётся.

## Проверка

Проверено в Chromium через Playwright: 208 тем и уникальные ID, сохранение отметок и заметок после перезагрузки, экспорт → сброс → импорт, поиск и переход, клавиатурные команды, отсутствие горизонтального переполнения на ширинах 1440, 1024 и 390 px, запуск с заблокированным localStorage. Приложение проверялось через `file://`.

Визуальный акцент — фиолетовый `#A78BFA`. Иконка вкладки встроена в HTML. Блок фокуса и декоративные подписи удалены; поле `pinned` сохранено в формате резервных копий для совместимости.
